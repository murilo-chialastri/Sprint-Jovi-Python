    Câmera Jovi

Um projeto que simula a interação de usuário com câmera, focando na melhoria de qualidade de imagem e otimização de armazenamento.

    Objetivo

Desenvolver um sistema de captura de imagens que resolve dois dos principais pontos de dor dos usuários:

Qualidade inadequada de imagens
Gerenciamento ineficiente de armazenamento

    Estrutura do Projeto

O projeto está organizado em 3 arquivos principais:

funcoesDaCamera.py - Funções de baixo nível da câmera (tirar foto, salvar, excluir, foco, etc)
cameraJovi.py - Orquestração central que integra todas as funções e gerencia o loop principal
main.py - Interface limpa que executa o sistema

     Funcionalidades

.Tirar foto
.Salvar imagem
.Excluir foto
.Foco de câmera
.Escolha de filtros

    Como Usar

Execute o programa:
    main.py
